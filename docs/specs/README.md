## Overview

octodns-metaname bridges two ecosystems:

- **OctoDNS** - DNS-as-Code framework with established patterns and conventions
- **OpsDev.nz** - Modern Python packaging approach (ruff, pyproject.toml, uv)

The module follows OctoDNS ecosystem patterns for compatibility while maintaining modern development practices.
